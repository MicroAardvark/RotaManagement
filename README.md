# RotaManagement
A Cross-platform Rota Application for Portfolio and Consumer Use

This repository will contain a rota application made for a cleaning company. Though this is made for actual use by this company, it will be made as more of a base application for any company to use, so I can use it in my portfolio.

For Safety and privacy reasons, the back end code is not included in this repo.
## Demo

The `demo` branch adds a browser-only demo build with made-up data and no server, for the portfolio. See [rota_management/DEMO.md](rota_management/DEMO.md) for how it works and how to build and deploy it.
